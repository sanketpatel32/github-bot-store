How it works

1

Build one file

go build turns any bot into a single small file. No runtime, no node_modules, no pip: copy it to any server and it just runs.

2

Point a webhook at it

In your repo settings, add http://your-server:PORT/webhook as a webhook. The bot now hears everything that happens.

3

Forget it's there

Each bot idles around 10MB of RAM. Run all 32 behind systemd or in tmux; your server won't notice.

4

No server? No problem

Every bot also runs as a GitHub Action — zero servers, zero cost, nothing to maintain. Copy one workflow file and you're done.
