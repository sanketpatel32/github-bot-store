How it works

1

Build one binary

go build any bot. No runtime, no node_modules, no pip — one static file you can scp anywhere.

2

Point a webhook at it

Repo → Settings → Webhooks → http://server:PORT/webhook. HMAC signature verification is built in.

3

Forget it's there

Each bot idles around 10MB RAM. Run all fifteen behind systemd or in tmux — your server won't notice.

4

Mix & match

Every bot is independent. Take one, take twelve, hack the main.go — they're short on purpose.

Pick a bot and a deployment style — get a ready-to-paste configuration.
