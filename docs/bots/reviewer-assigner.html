👀 reviewer-assigner

Looks at which files a pull request touches and assigns the right reviewers automatically — your own mini-CODEOWNERS, no GitHub Team plan needed.

type: webhook · port 8106 · events: Pull requests · permissions: pull-requests: write

Notes

  • Configure path prefixes in reviewers.json
  • Never assigns the PR author

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
