pr-size-labeler

When someone opens a pull request, this bot looks at how much code changed and sticks a size label on it — XS for tiny fixes, XL for monsters. Giant PRs are hard to review, so it gently nudges the author to split them.

Events
Pull requests
Permissions
pull-requests: write, issues: write
Port
8101

Good to know

  • Creates the size/* labels automatically
  • XL threshold is 800+ lines

Install

Download a Linux binary for amd64 or arm64 with checksums, or run the bot as a GitHub Action using a workflow from the repository.
