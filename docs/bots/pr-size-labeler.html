📏 pr-size-labeler

Labels PRs size/XS through size/XL by lines changed, and nudges authors to split giant PRs.

type: webhook · port 8101 · events: Pull requests · permissions: pull-requests: write, issues: write

Notes

  • Creates the size/* labels automatically
  • XL threshold is 800+ lines

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
