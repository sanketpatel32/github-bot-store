default-branch-ci-watchdog

Opens an issue when a GitHub Actions workflow fails on your main branch. It links to the failed run and closes the issue when a run passes.

Events
Scheduled hourly; checks push runs on the default branch
Permissions
actions: read, contents: read, issues: write
Port
8133

Good to know

  • Set CI_WORKFLOW to the workflow filename, such as ci.yml
  • Keeps one open alert per workflow and skips canceled runs
  • Builds from source until a release includes the bot

Install

Build the bot from source or use the config generator to create a GitHub Actions workflow that builds it for you.
