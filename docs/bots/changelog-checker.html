📋 changelog-checker

Commit status enforcing every PR updates the changelog — or explicitly opts out with a skip label.

type: webhook · port 8119 · events: Pull requests · permissions: statuses: write, pulls: read

Notes

  • CHANGELOG_FILE and SKIP_LABEL are configurable
  • Re-evaluates when labels change

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
