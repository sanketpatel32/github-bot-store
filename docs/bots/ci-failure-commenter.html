💥 ci-failure-commenter

When CI fails on a pull request, this bot posts a compact comment explaining what broke, with links to the logs. Updates the same comment when it goes green again.

type: webhook · port 8115 · events: Check runs, Check suites · permissions: checks: read, issues: write

Notes

  • Collapses repeat failures into one updated comment

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
