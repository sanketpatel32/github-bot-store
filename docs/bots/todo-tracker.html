📝 todo-tracker

Watches for new TODO and FIXME comments in the code and opens a tracking issue for each one, so they don't rot in the codebase forgotten. Closes the issue when the TODO is removed.

type: webhook · port 8108 · events: Push · permissions: issues: write, contents: read

Notes

  • Dedupes by content hash — no duplicates from merges

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
