🗃 project-board-sync

Keeps Projects v2 boards honest — new issues/PRs appear automatically, cards move as work progresses.

type: webhook · port 8132 · events: Issues, pull requests · permissions: issues: read, pulls: read, projects: write

Notes

  • Assigned work moves to In Progress, closed/merged to Done
  • GraphQL-powered; degrades gracefully if the board has no Status field

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
