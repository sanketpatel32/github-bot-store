🔍 duplicate-issue-hunter

When a new issue comes in, this bot searches existing ones and comments if it finds likely duplicates. Saves maintainers from answering the same bug report five times.

type: webhook · port 8107 · events: Issues · permissions: issues: write

Notes

  • Only fires on 2+ keyword overlap — vague issues stay quiet

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
