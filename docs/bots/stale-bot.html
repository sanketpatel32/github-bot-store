🥀 stale-bot

Hunts down issues and pull requests nobody has touched in 30 days, marks them as stale, and closes them a week later if nobody responds. Any comment resets the clock.

type: cron · port 8103 · events: None — polls every 12h · permissions: issues: write

Notes

  • Requires REPO=owner/name env var
  • STALE_DAYS and CLOSE_AFTER_DAYS configurable

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
