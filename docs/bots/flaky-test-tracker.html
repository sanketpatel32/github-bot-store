🎲 flaky-test-tracker

Catches flaky CI — checks that pass on retry with zero code changes — and files tracking issues.

type: webhook · port 8129 · events: Check runs · permissions: checks: read, issues: write

Notes

  • FLAKE_THRESHOLD controls sensitivity (default 3)
  • State persisted in flaky-state.json

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
