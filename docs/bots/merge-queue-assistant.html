🚦 merge-queue-assistant

Shows which pull request is next in line to merge, labeling the queue so everyone knows the order.

type: webhook · port 8130 · events: Pull requests · permissions: pulls: read, issues: write

Notes

  • Oldest queued PR is always the head
  • Head merging or closing promotes the next in line automatically

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
