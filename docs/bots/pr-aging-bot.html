pr-aging-bot

Flags pull requests that have been sitting open too long without review. Old PRs die in silence; this makes them visible.

Events
none (scheduled)
Permissions
pulls: read, issues: write
Port
8116

Good to know

  • Skips drafts by default (SKIP_DRAFTS=false to include)
  • Only writes when a PR crosses a tier boundary
  • Run nightly as a GitHub Action or crontab

Install

Download a Linux binary for amd64 or arm64 with checksums, or run the bot as a GitHub Action using a workflow from the repository.
