🚀 release-reminder

Nags you when lots of unreleased work has piled up on the main branch. A gentle push to actually ship.

type: cron · port 8124 · events: none (scheduled) · permissions: contents: read, issues: write

Notes

  • THRESHOLD_COMMITS sets the trigger (default 20)
  • Updates one managed issue instead of spamming

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
