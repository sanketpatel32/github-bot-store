docs-link-checker

Checks links in your documentation and README, and reports the dead ones. Nothing embarrasses like a 404 in the getting-started guide.

Events
none (scheduled)
Permissions
contents: read, issues: write
Port
8125

Good to know

  • Concurrent link checking with per-URL caching
  • HEAD-then-GET fallback for picky servers

Install

Download a Linux binary for amd64 or arm64 with checksums, or run the bot as a GitHub Action using a workflow from the repository.
