🚀 auto-merger

Merges pull requests automatically once they're approved and all checks pass. No more sitting around waiting to click the green button.

type: webhook · port 8110 · events: Pull requests, Check runs, Check suites, Status · permissions: pull-requests: write, contents: write

Notes

  • Repos without CI count as green
  • Create the automerge label first

Install

  • Prebuilt binaries — linux amd64+arm64, with checksums
  • Source and full README
  • Zero servers: run as a GitHub Action — see .github/workflows/bots-*.yml in the repo
